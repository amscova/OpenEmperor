## Reproduction

Use new output directories; existing proofs are protected:

```sh
cmake -S . -B .local/original-economy/oe44/repeat-release \
  -DCMAKE_BUILD_TYPE=Release -DOPENEMPEROR_USE_SYSTEM_SDL3=ON \
  -DOPENEMPEROR_ORIGINAL_MODEL_TEST_ROOT="$PWD/.local/gog-extracted/app"
cmake --build .local/original-economy/oe44/repeat-release --parallel 4
.local/original-economy/oe44/repeat-release/openemperor-elite-desirability-acceptance \
  --mode create --variant lean-med --search-ticks 40000 \
  --data "$PWD/.local/gog-extracted/app" --diagnosis oe44 \
  --output "$PWD/.local/original-economy/oe44/repeat-lean"
```

Repeat with `all-paid`, `staged` and `lean-med-extra-markets` into separate
fresh directories. The first actual17 event extends a creator to20,400 further
ticks; a40k search without17 remains a failed entry attempt. None of these
commands modifies the original installation or a protected input save.
