## Identity before selection

type through the observed selector/registration to a physical SG3 record.
Archive/bitmap fingerprints, native dimensions, Type30 side/base geometry,
mirror/alpha layout and placement anchor are checked independently. Neither
the three legacy curated pictures1512/1516/1520, a group name, model row nor
visual resemblance proves a House stage. Research and decoded proof remain
under `.local/original-economy/oe29/`; the source contract records exact evidence
and remaining gaps before the final metadata mapping is implemented.

The existing lifecycle evidence establishes Common2..10 as side2 and
Elite11..17 as side4. The actual authored empty Elite plot remains side2;
it cannot display an original side4 body before actual materialization.
Only proven compatible type/body combinations get original art. All other
types have an explicit named authored fallback and an honest parity boundary.
No stretching, silent nearest-stage substitution, invented mirror/variant,
new saved graphical state or geometry/authority permission follows from art.
If the original has several evidenced body variants but the World stores no
corresponding selector, a representative static presentation choice must be
explicitly distinguished from original per-instance variant reproduction.
